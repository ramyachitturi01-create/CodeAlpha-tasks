# Basic Chatbot

## Description

This project is a simple rule-based chatbot developed using Python.

The chatbot responds to predefined user inputs and continues the conversation until the user enters "bye".

## Features

- Greeting message
- Multiple predefined responses
- Help command
- Exit command
- User-friendly interaction

## Technologies Used

- Python

## Concepts Used

- Functions
- While Loop
- If-Elif-Else
- User Input
- Output Statements

## How to Run

python basic_chatbot.py
