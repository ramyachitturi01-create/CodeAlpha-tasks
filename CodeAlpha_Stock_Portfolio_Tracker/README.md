# Stock Portfolio Tracker

## Description

This project is a simple Stock Portfolio Tracker developed using Python.

The user enters stock names and quantities. The program calculates the investment value based on predefined stock prices and displays the total portfolio value.

The result is also stored in a text file.

## Features

- User input for stock names
- User input for quantity
- Investment calculation
- Portfolio summary
- Text file report generation

## Technologies Used

- Python

## Concepts Used

- Dictionary
- Loops
- Input / Output
- Arithmetic Operations
- File Handling

## Output

The program generates:

portfolio_report.txt

which contains the total investment value.
