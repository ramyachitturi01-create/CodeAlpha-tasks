# Hangman Game

## Description
This is a simple text-based Hangman Game developed using Python.

The player guesses a hidden word one letter at a time. The game allows six incorrect attempts before ending.

## Features
- Random word selection
- User letter guessing
- Six wrong attempts allowed
- Win and lose conditions
- Console-based interface

## Technologies Used
- Python

## Concepts Used
- Random Module
- While Loop
- If-Else Statements
- Lists
- User Input and Output

## How to Run

1. Open terminal.
2. Run:

python hangman.py

3. Follow the instructions displayed on screen.
